# iWork test files

Saved by the real apps from invented text. Rebuild with `make-fixtures.py`, on a Mac with the apps.

Never commit a file made from one of Apple's templates, or one holding an image: Apple's licence, clause 2.F ([why](../../../docs/design/iwork-reading.md#apples-licence-terms)).

| File | Proves |
|---|---|
| `agreement.pages` | Header, footer, footnote, comment, tracked change, table |
| `notes.pages` | Floating text box and table |
| `ledger.numbers` | Sheets, money, percent, date, formula, checkbox |
| `rows.numbers` | 300 rows, past a 256-row tile |
| `deck.key` | Moved slide, skipped slide, speaker notes |

Why: [`docs/design/iwork-reading.md`](../../../docs/design/iwork-reading.md).
