# NOTICE draft

> **Not legal advice. No lawyer reviews it.** The reasoning for this repository's `NOTICE` file, and an outline of the third-party
> notices that release bundles need. This label belongs to this page only; the real `NOTICE` file carries just the text in the box
> below. "Core" and "pro" are the two slots in this repository's code.

Status: draft, 2026-10-31. Companion to [dependency-review.md](dependency-review.md).

## Three files, three jobs

| File | Where | What it holds | Who keeps it |
|---|---|---|---|
| `LICENSE` | Root of `legallas` (and copied into every bundle) | The Apache-2.0 text, unchanged | Added in the first commit |
| `NOTICE` | Root of `legallas` (and copied into every bundle and fork) | Only the attributions Apache-2.0 section 4(d) makes every redistributor carry | By hand, rarely changes |
| `THIRD-PARTY-NOTICES` | Inside each release bundle, not in the repo | The licence text and copyright lines of every third-party package and asset the bundle contains | Generated by the release workflow from the built output |

Apache-2.0 section 4(d) requires anyone who redistributes the core to pass on the `NOTICE` text, so it should stay
short. The source repo vendors no third-party files, and none of the Apache-2.0 packages that reach a bundle ships a
`NOTICE` of its own, so the core's `NOTICE` needs no third-party entries.

## Proposed `NOTICE` for `Colorado-Startups/legallas`

```text
Legallas
Copyright 2026 Colorado Startups, LTD.

This product includes software developed by Colorado Startups, LTD.
and the Legallas contributors.

Release bundles of Legallas also contain third-party software and
fonts under their own licences. Their notices are in the
THIRD-PARTY-NOTICES file inside each bundle.
```

## Choices made

| Choice | Option A (drafted) | Option B | Note |
|---|---|---|---|
| Copyright line | `Copyright 2026 Colorado Startups, LTD.` | `Copyright 2026 Colorado Startups, LTD. and the Legallas contributors` | With the DCO and no CLA, outside contributors keep copyright in their own changes. Option A names the holder of the core as the brief says; the "developed by" line credits contributors |
| Year | First publication year only | A range updated each year | A single year is common and needs no upkeep |
| Third-party paragraph | Kept | Removed | Not required by any licence; it tells a reader of a fork where the bundle notices live |
| Product name | "Legallas" | Changed after the trademark search | The name waits on the full search (a launch gate) |
| Trademark sentence | In `TRADEMARKS.md` only | Also in `NOTICE` | Keeping it out of `NOTICE` avoids every fork having to repeat it |

The entity name follows the ownership papers: "Colorado Startups, LTD." (Colorado LLC), not the unrelated
"Colorado Startups LLC" on the same register.

## The installer repository (not this one)

The installer it builds carries three things: its own closed licence terms (kept there), this repository's `LICENSE` and `NOTICE` unchanged,
and one `THIRD-PARTY-NOTICES` covering the whole bundle.

### How the generator runs

`web/scripts/notices.ts`, from `web/`. The installer repository's release workflow calls it on CI, never on the Mac. CI's `checks` also runs it on every pull request that changes `web/`, so a package with no licence text fails there first.

```
 site build    LEGALLAS_METAFILE=meta/site.json npm run build               ─┐
 room Worker   wrangler deploy --dry-run --metafile meta/web.json           ─┤
 MCP Worker    wrangler deploy -c wrangler.mcp... --metafile meta/mcp.json  ─┤
 pdf.js files  dist/pdfjs/**/LICENSE*                                       ─┤
 reviewed      web/scripts/notices/*.txt (Rive, fonts' upstream lines)      ─┘
                                                                             ▼
               node scripts/notices.ts dist/THIRD-PARTY-NOTICES.txt dist meta/*.json
                         │                                    │
                         ▼                                    ▼
     a package with no licence text: exit 1        dist/THIRD-PARTY-NOTICES.txt,
     and nothing written                           served to members at /THIRD-PARTY-NOTICES.txt
```

| Where it's shown | Status |
|---|---|
